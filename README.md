# Chess Academy · أكاديمية الشطرنج

An interactive, bilingual (English / Arabic) chess course in a single HTML file.

- 13 lessons: board, pieces, special moves, check and mate, openings, tactics, endgames, strategy
- 10+ puzzles with a "Next puzzle" button
- Play against a simple computer opponent, or switch to 2 players
- One-click language switch with right-to-left layout for Arabic

## Run it

Open `index.html` in any browser. No build step, no dependencies.

## Host it

Enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
